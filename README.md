# Métodos Numéricos I

Repositório com códigos, exemplos e atividades da disciplina de Métodos Numéricos I (UDESC/CESFI – Engenharia do Petróleo).
Disciplina ministrada por Diego Alex Mayer, com monitoria de Guilherme Jordão Pitella.
Conteúdo focado na implementação computacional dos métodos numéricos utilizando Python.

## Conteúdos

- Análise de erros
- Raízes de funções
- Otimização
- Sistemas lineares
- Sistemas não lineares
- Ajuste de curvas
- Integração numérica

## Biibliotecas Ultlizadas

- NumPy
- Matplotlib
- Pandas
- Scipy
